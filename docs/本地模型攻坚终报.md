# 本地模型攻坚终报（2026-09-28 凌晨）

> 🏁 **【9/28 晚后记：本报告的结论已被推翻】** 攻坚结束数小时后，适配器架构取得突破——**模型推理（120B 调工具、做叙述）+ Python 适配器（组装八字段 JSON）+ 确定性审计（逐字段对账）**。该架构下本地 Nemotron-120B 三问 3/3 通过严格判据，随后 17 项测试全绿（含 192 组参数扫描）。**本地 120B 现为合同签发主力，云端 StepFun 仅作备用路由**（9/29 owner 终局口径）。本报告保留作攻坚过程记录：它如实记录了"为什么不能让裸模型直接签合同"，正是适配器架构的设计依据。

规则约束：仅可使用 NVIDIA（Nemotron）与 StepFun 模型。

| 候选 | 干预 | 结果 |
|---|---|---|
| StepFun step-3.7-flash（云，现役） | 七轮 SOP 收紧 | 3/3、12/12、16/16，七轮留档 |
