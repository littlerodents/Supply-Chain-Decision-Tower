
OpenClaw 2026.9.5 (ec9c1a1) — All your chats, one OpenClaw.

Usage: openclaw sessions tail [options]

Tail human-readable session trajectory progress

Options:
  --agent <id>         Agent id to inspect (required for multiple explicit
                       agents)
  --all-agents         Aggregate sessions across all configured agents (default:
                       false)
  --follow             Continue following for new trajectory events (default:
                       false)
  -h, --help           Display help for command
  --session-key <key>  Session key to tail (default: active sessions or latest)
  --store <path>       Legacy session store selector path
  --tail <count>       Number of existing trajectory events to show (default:
                       "80")
